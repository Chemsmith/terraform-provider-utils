# function: string_filter_trim

A utility function to trim a string to a specified length, removing unwanted prefixes and suffixes.

## Example Usage

```terraform
locals {
    input_string = "this-is-a-very-long-string-that-needs-trimming"
    substrings     = ["a", "that", "needs"]
    max_length   = 10
    keep_suffix  = false
}

output "output" {
  value = provider::utils::string_filter_trim(
    local.input_string,
    local.max_length,
    local.substrings,
    local.keep_suffix
  )
}

/* 
output = "this-is-ve"
*/
```

```text
string_filter_trim(input string, max_length number, substrings list(string), keep_suffix bool) string
```

## Arguments

<!-- arguments generated by tfplugindocs -->
1. `input` (String) A string to be trimmed.
1. `max_length` (Number) The maximum length of the output string.
1. `substrings` (List(String)) A list of substrings to remove from the input string.
1. `keep_suffix` (Boolean) Whether to keep the suffix of the input string if it exceeds the max length.

## Return Value

`string_filter_trim` will return the trimmed string.
